## 4. Architecture Overview

- **Android:** MVVM using Kotlin, Jetpack Compose, Room (SQLite), and Hilt. Audio relies on native SpeechRecognizer and TTS.
- **Web:** Next.js (App Router) PWA with React 19, Tailwind CSS v4, and Dexie (IndexedDB). Audio relies on Web Speech API and Web Audio API.
- **Boundaries:** Both clients operate fully locally with user-provided API keys stored securely in respective local vaults (EncryptedSharedPreferences / WebCrypto).

## 10. Security Threat Model

- **Assets:** User API key, locally stored vocabulary, study history.
- **Boundaries:** Local storage (Room/Dexie).
- **Threats:** Local physical compromise, XSS (Web).
- **Mitigations:** API keys stored via WebCrypto (Web) and EncryptedSharedPreferences (Android). Strict React escaping limits XSS.

## 2. Findings Identified & Remediated on 2026-11-27

| ID | Severity | Area | Finding & Remediation |
| :--- | :---: | :--- | :--- |
| **AUD-01** | Medium | Web SW Privacy | Unauthenticated navigation to public `/privacy` returned `200 OK` and cleared `isSessionTerminated` / IndexedDB `loggedOut` fail-safe. **Fixed:** excluded `/privacy` from `isProtectedAppRoute` (`sw.js`, `logout.ts`) and handled `/privacy` as a public route in `sw.js` without mutating session state. |
| **AUD-02** | Medium | Android Backup (`SEC-03`) | Android `exportBackup` and `applyImport` did not clamp/ignore a poisoned local `lastStudiedAt` (> `latestStudyTime`), causing export self-failure and allowing legacy poisoned rows to defeat valid incoming schedules. **Fixed:** bounded local `lastStudiedAt` in `BackupManager.kt` on both export and merge. |
| **AUD-03** | Medium | Streak Parity (`DATA-03`) | Web rejected `+1 day` eastward-timezone streaks accepted by Android, far-future dates zeroed valid streaks on both platforms, and Web `lastActivityTimestamp` dropped to `0` when active logs carried `timestamp: 0`. **Fixed:** unified `+1 day` tolerance, ignored dates `> today + 1`, and anchored `lastActivityTimestamp` on both clients. |
| **AUD-04** | Medium | Web Auth / Reverse Proxy | `POST /api/logout` compared `Origin` strictly against `new URL(request.url).origin`, causing false `403`s behind self-hosted TLS-terminating proxies. **Fixed:** added proxy-aware `isAllowedOrigin` (`web/src/lib/auth/origin.ts`, honoring `X-Forwarded-Proto`/`X-Forwarded-Host` only on Vercel or when `TRUSTED_PROXY_HEADER` is configured) and used `NextRequest.cookies`. |
| **AUD-05** | Low–Medium | Backup Schema Parity | Android `validateBackupJson` used permissive `optInt`/`optLong` and case-sensitive `remoteId` checks; Web `isRecord` accepted arrays (`xpAwards: []`); neither rejected duplicate `activityLog.date`; Web didn't trim transcript `fullText` in `applyImport`. **Fixed:** added strict integer helpers and lowercase `remoteId` normalization on Android, rejected arrays in `isRecord` on Web, rejected duplicate `activityLog` dates on both, and aligned transcript trimming. |
| **AUD-06** | Low | Web Auth Hardening | `POST /api/login` lacked `Origin` and `Content-Length` guards; `UpstashRedisThrottleBackend` omitted `cache: "no-store"` and `redirect: "error"`; legacy sync throttle wrappers remained exported. **Fixed:** added `isAllowedOrigin` (`403`) and 16 KiB size guard (`413`) to `/api/login`, added `cache`/`redirect` flags in `throttle.ts`, migrated tests to async API, and removed dead sync wrappers. |
| **AUD-07** | Low | Web AI & Resilience | Groq 5xx retries did not cancel unread response bodies; `429 Retry-After` was unparsed on both clients; `review.ts` omitted `now` in `calculateNextReview` and scanned all card events (`PERF-01`); Web lacked an App Router `error.tsx`. **Fixed:** cancelled unread 5xx bodies, added `parseRetryAfterSeconds` on Web & Android, upgraded Dexie to v11 with `[vocabularyId+reviewedAtTimestamp]`, passed `now` consistently, and added `web/src/app/(app)/error.tsx`. |
| **AUD-08** | Low | Policy & Lint Hygiene | `/privacy` page predated Redis session-revocation digests; Android Lint reported 2 `PluralsCandidate` warnings and 7 newer minor/patch dependency versions. **Fixed:** updated `web/src/app/privacy/page.tsx`, converted `ai_input_too_long` and `ai_message_too_long` to `<plurals>` (extending `tools/audit_repo.py` to check `<plurals>` parity), and updated `gradle/libs.versions.toml`. |
